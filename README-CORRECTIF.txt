FÉLY BUDGET — CORRECTIF D’INSTALLATION PWA

Ce correctif conserve les fichiers de l’application et ses fonctionnalités. Il ajuste l’identifiant du manifeste pour une publication GitHub Pages dans le sous-dossier /F-ly-Budget-/ et renouvelle le cache du service worker.

INSTALLATION DU CORRECTIF
1. Fais d’abord une sauvegarde de tes données depuis Fély Budget : Mes données > Exporter ma sauvegarde.
2. Ouvre le dépôt GitHub qui publie https://justfelicity.github.io/F-ly-Budget-/.
3. Dans l’archive, ouvre le dossier fely-budget-pwa et téléverse SON CONTENU (pas le dossier lui-même) à la racine du dépôt.
4. Accepte le remplacement de index.html, manifest.webmanifest, sw.js et des autres fichiers correspondants. Ne supprime pas le dépôt et ne change pas son nom.
5. Attends la fin du déploiement GitHub Pages.
6. Dans Chrome Android, ouvre le site, puis menu ⋮ > Installer l’application (ou Ajouter à l’écran d’accueil si c’est l’option proposée).

IMPORTANT
- Ne vide pas les données du site et ne supprime pas le stockage de Chrome : cela pourrait effacer les budgets enregistrés localement.
- Le correctif ne déplace pas les données locales : garde exactement la même adresse du site.
- Après déploiement, ouvre le site avec Internet, actualise une fois, puis teste le mode avion.
